	To summarize:


	C++ provides file handling via <fstream> header:
	Class			Purpose
	-----------------------
	ifstream		Read from file
	ofstream		Write to file
	fstream			Read + Write	
	
	
	If you are using fstream class for performing both input and output or you can perform input only or output only.
	
	If you are using the above mentioned fstream class to create object, you can use file opening mode flags as second argument. 
============================================================
	for example:
	1. using constructor. 
		fstream fObj(filename, mode);
		fstream fObj("fileExample.txt", ios::in);
			--> meant for input mode /read mode 
		fstream fObj("fileExample.txt", ios::out);
			--> meant for output mode /write mode 
		ofstream fObj("fileExample.txt", ios::app);
			--> meant for append mode
		ofstream fObj("fileExample.txt", ios::trunc);
			--> meant for truncate mode. Erase old file contents at the time of opening the file.
		fstream fObj("fileExample.txt", ios::in|ios::out);
			--> meant for input/output mode read/write mode
		fstream fObj("fileExample.txt", ios::in|ios::binary);
			--> meant for input in binary mode

	What are File Pointers?

	File pointers keep track of the current position in a file for:
		Reading --> get pointer
		Writing --> put pointer

	Function	Purpose
	-------------------
	tellg()		Current read position
	tellp()		Current write position
	seekg()		Move read pointer
	seekp()		Move write pointer	
	
From where you want to move your cursor/file pointer position.
	ios::beg  --> Begining of the file 
	ios::cur --> current position
	ios::end --> End of the file
